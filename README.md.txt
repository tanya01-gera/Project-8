# Job Market Analysis and Recommendation System

## Overview
This project analyzes job market trends using real-world job posting data and builds a job recommendation system.

## Features
- Salary analysis based on job titles
- Identification of emerging job categories
- Prediction of high-demand roles
- Country-wise salary comparison
- Job recommendation system using TF-IDF and cosine similarity
- Trend analysis and future predictions

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run
1. Open the Jupyter Notebook
2. Install required libraries (see requirements.txt)
3. Run all cells
